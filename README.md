# Aplikasi Web Kalkulator Canggih

Proyek ini adalah aplikasi web kalkulator canggih yang dibuat menggunakan Python dan framework Flask. Aplikasi ini memuat tiga kategori utama fitur kalkulator:

1. Operasi Aritmatika
2. Operator Logika
3. Transformasi Bilangan

## Fitur Utama

### 1. Operasi Aritmatika
- Penjumlahan (+)
- Pengurangan (−)
- Perkalian (×)
- Pembagian (÷)
- Pangkat
- Akar
- Modulus
- Floor division

### 2. Operator Logika
- AND
- OR
- NOT
- XOR
- NAND
- NOR

### 3. Transformasi Bilangan
- Konversi basis: Decimal, Binary, Octal, Hexadecimal
- Konversi suhu: Celcius, Fahrenheit, Kelvin, Reamur
- Konversi mata uang sederhana: IDR ke USD, EUR, SGD, dll. (rate statis)
- Faktorial dan Deret Fibonacci (bonus)

## Tujuan
Membuat aplikasi web interaktif yang dapat melakukan perhitungan matematika, operasi logika, dan konversi nilai secara mudah dan cepat menggunakan Flask.

## Cara Menjalankan
1. Pastikan Python dan Flask terinstal.
2. Jalankan aplikasi Flask.
3. Buka browser dan akses aplikasi di alamat yang ditentukan.

## Struktur Aplikasi
- `app.py` atau `main.py`: file utama Flask
- `templates/`: file HTML
- `static/`: file CSS dan JS

## Catatan
Rate konversi mata uang menggunakan nilai statis untuk keperluan tugas.
